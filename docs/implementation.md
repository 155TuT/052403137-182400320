# 原型与实现对照

视觉来源为课程仓库 `homework/pair/task3/ans/assets/prototype/screens.json` 与 `figma-builder.template.js`，矢量图标使用同目录下的原有 SVG。原型的手机画布为 390 × 844，系统栏 42 px、页面导航 64 px，内容两侧 16 px、卡片间距 12 px。详情沿用 24 px 标题、72 px 物品插画、白色圆角卡片、浅绿色提示卡及固定底部操作区。

| 原型来源 | 程序实现 | 范围说明 |
| --- | --- | --- |
| `detail`：蓝伞招领详情 | 物品信息、保管说明、公开联系方式、认领与线索入口 | 描述、地点、日期和联系人来自当前记录；服务点信息仅用于原有示例 |
| `keys_detail`：银色钥匙详情 | 同一详情组件读取钥匙记录，本人可编辑、标记归还 | 真实新发布记录由发布者维护，不自动声称服务点已接收 |
| `cup_lost_detail`：水杯寻物详情 | 根据寻物类型切换标题、帮助说明和“已找到”状态 | 联系发布者核对，不自动判断相似物品属于同一人 |
| `detail_done`：完成状态 | 显示发布者标记的“已找到 / 已归还”，收起联系及重复完成入口 | 不将本人更新状态表述为双方核验或服务点确认 |
| 通用卡片及底部按钮 | 内容区域单独滚动，操作区固定在手机视口底部 | 用户上传的照片和实际联系方式会增加内容高度 |

`Detail.jsx` 接收当前物品与当前用户。只有记录所有者可见编辑和完成按钮；完成需经过可取消的确认面板，并等待保存回调成功。保存失败时保留原状态和错误提示。联系方式直接展示为文本，复制成功后才提示成功；无法访问剪贴板时选中文字供手动复制。

本次实现以“发布—浏览或搜索—详情—联系—发布者更新状态”为闭环。原型中的完整服务点后台、双向核验、奖励、申诉及真实消息服务不属于已实现能力；样例记录和本地身份也不代表接入真实校内运营。

设计来源：[拾伴 Figma 文件](https://www.figma.com/design/JTLCFQJNsz3Ip4U7KElBEj?node-id=16-8524)。当前画布优先于较早的原型生成脚本；搜索结果按当前单列文字卡实现。头像统计及状态取真实本地记录，详情增加实际联系方式和所有者操作，因此动态文案、实际照片和长输入不会与静态样例逐字一致。本次未声称覆盖 116 个原型状态或得到全页面零像素差异。

`web/index.html` 的脚本和样式已经内联，SVG、字体采用相对路径。通过 `npm run preview` 可重复运行本次已验证的构建版本。开发地址、预览地址与直接打开文件的本地存储彼此独立。

Noto Sans SC 从本机已安装的字体转换为 WOFF2，字形未裁剪；随项目保留 `public/assets/OFL-NotoSansSC.txt`。未使用远程字体或 CDN，页面运行时无需向外部服务发送表单、联系方式或照片。

## 修复说明

仅同步全局 `revision` 不能保护已经打开的编辑表单：另一标签页保存后，旧表单仍可能利用新版本号覆盖新内容。现在编辑会话单独保存原记录快照；保存其他记录则基于最新存储合并，以保留无关修改和活动记录。结案和丢弃确认框也固定打开时的记录快照，防止确认期间覆盖更新。

同一存储来源下支持 Web Locks 的浏览器会串行执行读、校验、写入。未提供 Web Locks 的环境仍有快照与版本检查，但不能保证不同标签页同时写入时的原子性；本次多标签页验收使用 Chrome 的本地 HTTP 预览。该机制不是服务器同步或账号权限系统。

保存前统一迁移记录，移除旧的 `timeLabel` 派生字段，避免新发布记录在立即编辑或结案时因内存与存储表示不同而误报冲突。构建产物已重新生成到 `web/`。

# “我的记录”标签交互

对应 [issue #6](https://github.com/155TuT/052403137-182400320/issues/6)，验证日期：2026-10-10。

“我发布的 / 我认领的 / 我协助的”保留 tabs 语义。选中项使用绿色背景与深色边框；键盘焦点另有外轮廓，焦点离开后仍保留选中提示。移除了样式文件末尾将选中项重新覆盖为白色的规则。

- 鼠标点击切换标签；只有当前标签进入常规 Tab 顺序。
- 左右方向键移动焦点并立即切换内容，首尾循环；Home / End 跳到第一项 / 最后一项。
- Tab 从标签进入当前面板，再进入面板中的可操作记录；空面板也可以接收焦点。
- 三个标签与三个面板通过 `aria-controls`、`aria-labelledby` 对应，非当前面板使用 `hidden` 隐藏。
- 从详情返回或在首页与“我的”之间切换，保留当前标签选择。

## 验证

- `npm test`：现有 72 项测试通过；`npm run build`：成功；`git diff --check`：通过。
- Chrome 对最终 `web/` 构建的本地预览实测：依次点击三项，始终只有一个选中标签、一个可见面板、一个 `tabIndex=0` 的标签；DOM 面板关联正确。
- 实测左右移动、双向首尾循环、Home / End，真实焦点与选中项同步；Tab 从前一控件进入当前标签，再进入当前面板。
- 有发布记录时，可继续 Tab 到记录并用 Enter 打开详情；认领和协助空列表时，可进入面板再离开，隐藏的发布记录不进入焦点顺序。
- 焦点进入面板后，标签外轮廓消失、绿色选中背景保留；返回详情前的页面与跨页面导航均保留选择。当前 390px 页面布局无标签横向溢出。

本次键盘与视觉行为通过真实 Chrome 验收，未新增模拟 DOM 的测试依赖；现有数据层测试不作为键盘行为的验证证据。

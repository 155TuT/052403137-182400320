对应 [issue #4](https://github.com/155TuT/052403137-182400320/issues/4)。物品类别、默认插画和相关详情标题由 `src/itemPresentation.js` 统一管理，表单选项与数据校验复用同一份类别列表。

| 类别 | 本地素材 | 表现内容 |
| --- | --- | --- |
| 雨伞 | `public/assets/umbrella.svg` | 保留原有雨伞插画 |
| 钥匙 | `public/assets/keys.svg` | 保留原有钥匙串插画 |
| 水杯 | `public/assets/bottle.svg` | 保留原有保温杯插画 |
| 数码 | `public/assets/electronics.svg` | 手机与无线耳机 |

| 其他 | `public/assets/other.svg` | 通用随身收纳包 |

新增的四张素材为本仓库原创可编辑 SVG：128×128 画布，深色圆角描边，沿用荧光绿、淡蓝和暖橙配色。文件包含 `title`、`desc` 与具名图层/路径，无嵌入位图或外链。原有 SVG、字体和许可证保留。

## 展示与保存规则

- 类别由用户选择；物品名称不自动覆盖类别。保温杯属于水杯，耳机属于数码。未选类别的草稿和无法识别的历史类别显示通用插画；发布仍需通过类别校验。
- `ItemArtwork` 统一用于编辑/预览标题、首页、搜索、草稿、“我的”和详情标题。存在本地上传照片时优先显示第一张；详情与预览继续保留完整照片列表。
- 默认插画读取当前 `category`，不读取旧 `image`。修改类别后立即显示对应插画；详情标题按类别、寻物/招领类型、转报/服务点关系及完成状态生成，不再根据图片猜测业务含义。
- 发布和保存草稿时同步规范兼容字段 `image`，不修改用户的 `images`。旧存储无需重置或升级版本，加载后按当前类别展示；再次保存时更新兼容字段。
- 构建后四张新增 SVG 同步到 `web/assets/`，`web/index.html` 使用同一套展示逻辑。页面运行不请求外部图片。
